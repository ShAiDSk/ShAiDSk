<table>
<tr>
<td width="50%" valign="top">

**🏗️ Architecture**
- Multi-vertical subdomain platform — 6 verticals (Insurance, Mutual Funds, Equity, PMS, AIF, Tax) routed via `DetectSubdomain` middleware
- Three runtime planes: Public · Operations · Client Portal
- Four processing models: Sync · Async (queues) · Event-driven (Reverb WebSockets) · External intelligence (FastAPI)
- Cross-subdomain SSO with shared session state

**🤖 AI Intelligence**
- AI Assistant with RAG over indexed knowledge base
- Streaming responses (OpenAI GPT-4 Turbo / Google Gemini)
- Function-calling registry with structured tools
- Vector chunks for similarity search

</td>
<td width="50%" valign="top">

**🔍 Identity Resolution (CIRS)**
- 6-stage pipeline: Normalize → Deterministic → Probabilistic → Score → Merge → Review
- ML-based fuzzy matching via FastAPI microservice
- Auto-merge above confidence threshold, human review queue below
- Master ledger with audit trail

**📈 Equity & Real-Time**
- Live NSE market data — Yahoo → Google → NSE fallback chain
- Laravel Reverb WebSockets · Echo client streaming
- Per-client portfolio holdings + master ledger
- Fraud detection via Python FastAPI (Isolation Forest + rules)

</td>
</tr>
</table>
